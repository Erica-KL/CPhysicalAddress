# CPhysicalAddress
part one 
There are 2 considerable variables the local variable (local_var) an integer that belongs on the stack and the pointer (heap_ptr) which in the stack points to the heap through malloc -lib c memory allocation function. It should show virtual and physical addresses of each. The virtual address allows us to find the virtual page number which is found by dividing 4096 and the offset - the displacement from the base. vpn*8 locates the entry for the page map aferwards we check whether the page is in RAM. The offset is the same and is needed in both circumstances. The physical adress needs the PFN multiplied by 4096 and the offset is added. 
part 2
This uses a parent and child relationship created by the Fork () function which executes this. Malloc is used in the prior but this one uses mmap because both processes map to the same physical memory. MAP_SHARED ensures that both virtual adresses can be shared, read, and written between.  MAP_ANONYMOUS is not backed by a file and only exists in RAM. The child runs slighlty before parent as the child writes its value first to ensure it's shared before the parent writes as per wait(). Both processes have the same physical address which confirms the child Map_Shared is functioning.
